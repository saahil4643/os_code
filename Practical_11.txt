NETWORKING FUNDAMENTALS – PRACTICAL 11

Aim

To establish a Local Area Network (LAN) by connecting multiple PCs
through a switch and verify connectivity using the ping command.

Requirement

-   Computer or laptop with Cisco Packet Tracer
-   One Ethernet switch and two or more PCs
-   Copper straight-through cables

Theory

A Local Area Network (LAN) connects computers within a limited
geographical area, such as a laboratory or office. In a switched
Ethernet LAN, each PC is connected to a switch using an Ethernet cable.
The switch forwards Ethernet frames between connected devices. For PCs
in the same subnet to communicate directly, each must have a unique IP
address and the same appropriate subnet mask. The ipconfig command
displays the PC’s network configuration. The ping command uses ICMP echo
messages to check whether another device is reachable over the network.

Procedure

1.  Place one switch and two or more PCs in the Packet Tracer workspace.
2.  Connect each PC to a separate switch port using Copper
    Straight-Through cables.
3.  Configure PC0 with IP address 192.168.1.1 and subnet mask
    255.255.255.0.
4.  Configure PC1 with IP address 192.168.1.2 and subnet mask
    255.255.255.0.
5.  For an additional PC, use another unique address such as 192.168.1.3
    in the same subnet.
6.  On PC0, open Desktop > Command Prompt and run ipconfig to verify its
    configuration.
7.  Run ping 192.168.1.2 to test communication with PC1.
8.  Repeat the test with other PCs and record the responses.
9.  If a request times out, check the IP addresses, subnet masks, cable
    connections and link status.

Result

The PC LAN was configured successfully, and communication between
connected computers was tested using ping.

Conclusion

A LAN was established by connecting PCs through an Ethernet switch. IP
configuration was checked using ipconfig, and the ping command was used
to verify communication between computers.
